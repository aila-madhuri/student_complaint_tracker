# Student Complaint Tracker

A web-based Student Complaint Tracker developed using Python and Streamlit. 
This application allows students to submit complaints and helps manage and track complaint records.

## Features

- Student complaint submission
- Store complaints in a database
- View complaint records
- Simple and user-friendly interface
- Built using Python and Streamlit
- SQLite database integration

## Technologies Used

- Python
- Streamlit
- SQLite
- Git & GitHub
